# sha256()

Hashes a local file with the implementation `download()` checks against.

```scrut
$ cp -R "$TESTDIR/fixtures/sha256/." "$TMPDIR" && cd "$TMPDIR"
```

The same hash `tests/fixtures/download/download.star` pins for this file:

```scrut
$ starcm hash.star
success=True changed=False value=77343010f71b589c625b217d4a544a08dbcf49ab1ba1e99b369c4a6c378bf314
```

```scrut
$ starcm missing.star 2>&1
Traceback (most recent call last):
  missing.star:2:7: in <toplevel>
Error in sha256: open missing.txt: no such file or directory
[1]
```
