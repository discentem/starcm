# sha256

[← All functions](../README.md)

Use `sha256` to hash a local file. It uses the same implementation
[download](download.md) checks against, so its value can be pinned straight
into `download(sha256 = ...)`.

## Syntax

```python
load("starcm", "sha256")

sha256("agent.pkg", label = "hash agent").value
sha256(path = "agent.pkg", label = "hash agent").value
```

## Arguments

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `path` | string | required | The file to hash, positionally or as `path =`, relative to the directory starcm runs in. `~` is not expanded. |

`sha256` also takes the [common arguments](../common-functionality.md#common-arguments):
`label` (required), `only_if`, `not_if`, `timeout`, `working_directory` and
`what_if`. Only `only_if` and `not_if` affect it.

## Returns

A [starcm_result](../common-functionality.md#starcm_result) with `success =
True`, `changed = False` and `value` set to the file's sha256 as 64 lowercase
hex characters. A file that can't be read stops the run.

## Examples

Each example runs in a scratch copy of
[docs/fixtures/sha256/](../fixtures/sha256).

```scrut
$ cp -R "$TESTDIR/../fixtures/sha256/." "$TMPDIR" && cd "$TMPDIR"
```

### Hash a file

<!-- fixture: ../fixtures/sha256/hash.star -->
```python
load("starcm", "sha256")

r = sha256("payload.txt", label = "hash payload")
print("success=%s changed=%s" % (r.success, r.changed))
print(r.value)
```

```scrut
$ starcm hash.star
success=True changed=False
2cddd2be80b2292ca06a9c962200f04a823cb5f614031951da92c2ffeba87e7d
```

It's the same hash `shasum -a 256` (or `sha256sum`) prints:

```scrut
$ (command -v sha256sum >/dev/null && sha256sum payload.txt || shasum -a 256 payload.txt) | cut -d" " -f1
2cddd2be80b2292ca06a9c962200f04a823cb5f614031951da92c2ffeba87e7d
```

### Act on whether a file changed

<!-- fixture: ../fixtures/sha256/compare.star -->
```python
load("starcm", "sha256", "write")

EXPECTED = "2cddd2be80b2292ca06a9c962200f04a823cb5f614031951da92c2ffeba87e7d"
actual = sha256(path = "payload.txt", label = "hash payload").value
write("payload is intact", label = "ok", only_if = actual == EXPECTED)
write("payload changed!", label = "changed", not_if = actual == EXPECTED)
```

```scrut
$ starcm compare.star
payload is intact
INFO: [changed]: skipping write(label="changed") because not_if was true
```

```scrut
$ echo "edited" >> payload.txt && starcm compare.star
INFO: [ok]: skipping write(label="ok") because only_if was false
payload changed!
```
