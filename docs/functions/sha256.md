# sha256

[← All functions](../README.md)

Use `sha256` to hash a local file. It uses the same implementation
[download](download.md) checks against, so its value can be pinned straight
into `download(sha256 = ...)`.

## Syntax

```python
load("starcm", "sha256")

sha256(agent)   # agent = download(...): a result passed in stands for its value
sha256(path = "/opt/agent/agent.pkg")
```

## Arguments

| Argument | Type | Default | Description |
| --- | --- | --- | --- |
| `path` | string | required | The file to hash, positionally or as `path =`. An absolute path; a leading `~` expands to the home directory. |

`sha256` only reads, so it's a plain function: it takes no `label` or other
[common arguments](../common-functionality.md#common-arguments) and returns
its answer directly, not a `starcm_result`. Use `if` to call it
conditionally. It runs under `what_if` too.

## Returns

The file's sha256 as 64 lowercase hex characters. A file that can't be read
stops the run.

## Examples

Each example runs in a scratch copy of
[examples/sha256/](../../examples/sha256).

```scrut
$ cp -R "$TESTDIR/../../examples/sha256/." "$TMPDIR" && cd "$TMPDIR"
```

### Hash a file

```python
# examples/sha256/hash.star
load("starcm", "sha256", "here")

print(sha256(here("payload.txt")))
```

```scrut
$ starcm hash.star
2cddd2be80b2292ca06a9c962200f04a823cb5f614031951da92c2ffeba87e7d
```

It's the same hash `shasum -a 256` (or `sha256sum`) prints:

```scrut
$ (command -v sha256sum >/dev/null && sha256sum payload.txt || shasum -a 256 payload.txt) | cut -d" " -f1
2cddd2be80b2292ca06a9c962200f04a823cb5f614031951da92c2ffeba87e7d
```

### Act on whether a file changed

```python
# examples/sha256/compare.star
load("starcm", "sha256", "write", "here")

EXPECTED = "2cddd2be80b2292ca06a9c962200f04a823cb5f614031951da92c2ffeba87e7d"
actual = sha256(path = here("payload.txt"))
write("payload is intact", label = "ok", only_if = actual == EXPECTED)
write("payload changed!", label = "changed", not_if = actual == EXPECTED)
```

```scrut {output_stream: combined}
$ starcm compare.star
payload is intact
INFO: [changed]: skipping write(label="changed") because not_if was true
```

```scrut {output_stream: combined}
$ echo "edited" >> payload.txt && starcm compare.star
INFO: [ok]: skipping write(label="ok") because only_if was false
payload changed!
```

## Errors and edge cases

These are here mostly as tests: CI runs them to check error messages and
behaviour that the examples above don't show. They run in the copy of
[examples/sha256/edge/](../../examples/sha256/edge).

```scrut
$ cd "$TMPDIR/edge"
```

### A missing file stops the run

```python
# examples/sha256/edge/missing.star
load("starcm", "sha256", "here")
sha256(here("missing.txt"))
```

```scrut
$ starcm missing.star 2>&1
Traceback (most recent call last):
  missing.star:2:7: in <toplevel>
Error in sha256: sha256: open .*[/\\]missing\.txt: (no such file or directory|The system cannot find the file specified\.) (regex)
[1]
```
